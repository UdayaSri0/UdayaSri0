## 👋 About me

I’m **Udaya Sri**, a computing lecturer and software developer based in Sri Lanka. I teach and work across **networking, cybersecurity, cloud computing, and programming**, and I lead projects at **USking Studios**.

I enjoy turning technical ideas into practical software, hands-on labs, and resources people can learn from. My current interests include Linux desktop development, network engineering, IoT security, and RF experimentation.
